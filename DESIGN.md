# Priyanshi Rana Portfolio — Design Decisions

## Direction

This is a **career-fair portfolio / online résumé** for an AI-focused Computer Science student. The visual language keeps the editorial structure of the first version, but shifts to a muted, recruiter-friendly palette and denser résumé rhythm so a hiring manager can scan roles, dates, technologies, and outcomes quickly.

## System

- **Palette:** Deep ink navy (`#213747`) establishes authority; dusty blue (`#496B83`) carries the technical focus; muted clay (`#A76352`) marks emphasis and certification content; sage (`#72877E`) provides a quiet availability signal; paper, sand, and mist neutrals keep the page calm.
- **Typography:** DM Serif Display creates an editorial voice for the name and section titles. DM Sans handles readable body copy. DM Mono is reserved for dates, labels, technology metadata, and section markers.
- **Composition:** A compact hero introduces Priyanshi and the photo placeholder. After the contact ribbon, the sections follow the résumé order exactly: Education, Experience, Projects, Technical Skills, and Certifications.
- **Recruiter scanning:** Each résumé section has a numbered label, clear section heading, visible date/company context, short bullet blocks, and compact technology tags. The navigation follows the same ordering and links directly to the main sections.
- **Motion:** Links, buttons, and project panels use short transform-based feedback. Reduced-motion preferences disable all nonessential transitions.

## Content Notes

All employment, education, projects, technical skills, and certifications are based on the supplied résumé. Since no portrait, LinkedIn URL, or GitHub URL was supplied, the site uses a clearly labeled photo placeholder and presents LinkedIn / GitHub as non-clickable labels rather than fabricating destination URLs.
